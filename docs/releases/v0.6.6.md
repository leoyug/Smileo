# V0.6.6

发布日期：2026-10-13

- Dock 导航项和偏好按钮悬停时，使用与扇形照片组件相同的轻触音效和音量；沿用全站音效开关，触屏不播放悬停音效，进入图标内部不会重复触发。
- 关于页“邮件”默认显示灰色下划线，悬停或键盘聚焦时显示邮箱地址并展开 Feather 复制图标，下划线沿用其他链接的强调色；离开后恢复“邮件”和灰色下划线。点击复制成功后切换为 Feather 勾选图标与“已复制”，1.5 秒后按当前悬停或聚焦状态恢复；保持复制提示期间的悬停区域稳定。
- 扩展现有 TextLink 的 copyText 属性，复用文字与图标切换动效，支持键盘、触屏、减少动态效果和复制失败反馈；不支持 Clipboard API 时保留邮件链接。补充设计系统示例与交互 token，同步更新字体子集。

验证：`npm run build` 通过；Astro 检查无错误、警告，保留一条已有工具脚本提示；99 张已发布照片与 99 个照片资产审计通过；项目、摄影、写作顺序审计及 28 项导入、排序、批量操作与短名测试通过；生成 124 个静态页面，无草稿资产。浏览器检查 Dock 与照片组件的悬停音效、音效开关、触屏及重复触发保护；邮箱地址显示、下划线颜色、实际剪贴板内容、1.5 秒恢复、复制失败、键盘、触屏、深色主题与减少动态效果通过。首页、主要列表、文章详情、404、开发设计系统及 375px 移动导航检查通过。测试浏览器已正常关闭，无残留测试进程。`git diff --check` 通过。
