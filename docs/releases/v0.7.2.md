# V0.7.2

发布日期：2026-10-22

- 项目页移除重复的精选项目模块，改为一份项目档案列表，顶部提供「全部 / 项目 / 案例 / 实验」分类切换；首页继续保留精选项目。
- 统一项目分类：Wanderland 为个人项目，宅畅想 App、宅畅想官网和亦我家装后台为设计案例，其余项目为实验探索；按稳定项目 ID 配置，与上线状态分别维护。
- 分类 Tab 采用仅选中项展开图标的交互，胶囊与图标同步平滑切换，支持连续反向切换、键盘操作、减少动态效果、分类播报和无 JavaScript 回退；从项目详情返回后保留原分类。
- Tab 使用 16px、1px 描边图标：「全部」为收纳图标，「项目」为代码文件夹图标。轨道无边框，深色轨道为 #111，选中项复用较浅的 surface-2 色彩 token；支持亮暗主题。
- Tab 总高保持 40px：轨道内边距 4px，单项内边距为上下 4px、左 10px、右 12px，相邻项间距 0px，图文间距 2px。介绍文字到轨道的间距恢复为桌面 80px、移动端 64px，键盘焦点保持完整可见。
- 首页精选项目悬停封面向下位移由 12px 调整为 16px，标签最终位置下移 2px。
- 同步项目分类领域说明、产品方案、设计规范、开发设计系统示例和字体子集；修正分类筛选后列表分隔线的位置。
- `package.json` 与 `package-lock.json` 版本号由 `0.7.1` 更新至 `0.7.2`，未新增依赖。

验证：`npm run build` 完整通过；Astro 检查 136 个文件，0 errors / 0 warnings。42 项自动化测试、99 张已发布照片与 297 个照片资产审计及内容顺序审计通过；生成 115 个静态页面，并移除 27 个草稿或未引用媒体文件。

本轮浏览器验证累计覆盖开发环境的 9 / 1 / 3 / 5 条分类结果、图标仅在选中时展开且不拉伸、连续切换、键盘、减少动态效果、详情返回与浏览器后退、无 JavaScript 回退及设计系统独立实例。最终尺寸检查覆盖 1280px、390px、320px，确认总高 40px、轨道内边距 4px、介绍到轨道间距 80px / 64px，亮暗主题无横向溢出，键盘焦点未被裁切。测试浏览器与控制进程均已正常关闭并复查无残留。`git diff --check` 通过。
