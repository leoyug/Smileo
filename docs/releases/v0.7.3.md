# V0.7.3

发布日期：2026-10-23

- 根据 Figma 将 Wanderland 更新为 Wispora 个人视觉灵感库，替换名称、简介、原始品牌封面和项目参数；首页精选及项目列表自动使用新内容，移除旧档案叠图引用。
- 按「为什么要做 / 关于这个应用 / 遇到的挑战 / 思考」重写项目正文，整理收集场景、技术实现与瀑布流拖拽的取舍，修正文案中的旧名称；保留稳定地址 `/projects/wanderland`、展示顺序、个人项目分类与草稿状态。
- 新增可选项目工具字段，详情页展示职责、平台、时间和工具四项参数：桌面四列、手机两列，沿用阅读栏、主题 token 和正文排版；未填写工具的项目继续使用既有简洁参数行。
- 扩展现有 `DetailToc`，支持使用设计中的原始返回和回到顶部 SVG，保留目录高亮、历史返回及封面图片预览；Keystatic 同步支持职责与工具编辑。
- 同步开发设计系统示例、内容领域说明、产品方案、设计规范、内容发布核对记录与字体子集。
- `package.json` 与 `package-lock.json` 版本由 `0.7.2` 更新至 `0.7.3`，未新增依赖。

验证：`npm run build` 完整通过；Astro 0 errors / 0 warnings，42 项自动化测试、99 张已发布照片与 297 个照片资产审计及内容顺序审计通过；生成 115 个静态页面，移除 28 个草稿或未引用媒体文件。`git diff --check` 通过。

本次内容改动已于前一轮完成 1440px 深色桌面和 390px 亮色手机验证：封面及 SVG 原始资产、标题与正文排版、四列与两列参数、无横向溢出、目录跳转和回到顶部、键盘封面预览与 Esc 关闭、手机导航、列表进入与返回均通过。首页、写作列表、文章详情、404、开发设计系统及其他项目原有参数布局复查通过，浏览器无页面错误。独立审阅结论为 ship；测试浏览器与控制进程已关闭并复查无残留。

本次保存版本并推送当前工作分支，不合并主干或执行网站部署；项目内容继续保持草稿。
