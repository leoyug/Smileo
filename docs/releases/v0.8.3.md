# V0.8.3

发布日期：2026-10-30

- 补齐公开页面的完整英文版本，覆盖界面、简历、作品集、7 篇文章与 4 个项目案例；英文地址使用 `/en/`，同步 canonical、hreflang、分享元数据、RSS、内部链接、旧址跳转及 404。中英文复用内容发布状态、稳定短名、图片与章节 ID。
- 底部偏好面板与独立作品集支持语言切换，保留当前页面、查询参数和章节锚点，记录语言偏好并恢复无锚点页面的滚动位置；同步页面标题、返回入口、筛选、复制反馈、照片灯箱与图集等客户端文案。
- 统一主题切换与初始化逻辑，修复浏览器存储不可用时的回退；调整作品集亮暗主题图标、文字标记的配色、位置与形状，宅畅想官网入口改为完整案例，并保存项目外部网址移除。
- 优化中英文长标题、紧凑文章行与项目索引在桌面和窄屏的排列、日期层级和间距；关于页头像保持固定比例，英文版等比例缩至 200px，中英文内容均遵守 592px 阅读栏上限。
- 文章与项目详情目录的选中、悬停和聚焦文字由 `--color-ink` 降为 `--color-copy`，未选中文字使用新增的 `--color-subtle`；保留原有目录结构、滚动高亮和键盘行为。
- 改进 GitHub 贡献图解析并保存本地快照，在远程请求失败时继续展示已有记录；同步多语言领域说明、维护文档、设计依据与字体子集。
- 增加语言路径与正文对应检查、英文静态出版审计；显式声明 Markdown 与 HTML 解析依赖。`package.json` 和 `package-lock.json` 从 `0.8.2` 更新至 `0.8.3`。

验证：`npm run build` 完整通过；Astro 0 errors / 0 warnings，保留 5 项未使用变量或导入提示。49 项自动化测试、99 张已发布照片及 297 个照片资产审计、内容顺序审计通过。生成 243 个静态页面，121 个英文页面通过正文、元数据、可访问名称、锚点与内部链接审计，移除 15 个草稿或未引用媒体文件。
