# V0.8.7

发布日期：2026-11-05

- 整合首页与个人介绍，补充联系方式、常用工具及求职入口；简介页以姓名作为一级标题，精简底部导航，旧中英文关于页跳转至对应首页。
- 自托管 Geist Sans 常规与斜体可变字体，保留中文字体回退与 Geist Mono 等宽信息样式；调整暗色正文颜色，同步字体来源、许可与设计说明。
- 更新职业履历及中英文文案，英文校名使用 UESTC，教育经历的校名与年份按文字基线对齐。
- 首页首屏外区块及文章、项目详情正文进入视口时逐项播放入场动效；处理键盘聚焦、减少动态效果、历史返回和路由切换时的动画清理，避免正文共享过渡与滚入动画重复位移。
- 修复摄影详情放大结束后的图片闪烁：保留预览图，待完整图片解码、显示后再交接；完整图片加载失败时继续显示预览图。
- 共用详情目录行高从 24px 缩至 22px，与正文至少保留 16px 留白；同步调整中屏目录宽度、窄屏适配及设计系统示例。
- 文章和项目详情统一使用新的 24×24 返回与回到顶部 SVG，沿用亮暗主题颜色及悬停、键盘聚焦行为。
- 回到顶部按钮初始隐藏，达到页面可滚动距离的 30% 后上移淡入，回到阈值以内下移淡出；复用 16px 位移及 840ms 时长，支持中途反向接续，隐藏时不可点击或聚焦，减少动态效果时直接显隐。
- 优化详情正文各级标题的段前、段后留白，更新 GitHub 贡献图快照。
- `package.json` 与 `package-lock.json` 从 `0.8.6` 更新至 `0.8.7`。

验证：`npm run build` 完整通过，120 个英文页面通过出版审计。已检查生产预览中的首页、移动导航、主要列表、照片页、简介、中英文项目与文章详情、真实 404，以及中英文旧关于页跳转和开发环境设计系统页，无页面脚本错误。本次迭代还验证了摄影详情慢网交接、目录响应式留白、图标亮暗与聚焦状态，以及回到顶部按钮的 30% 阈值、位移淡入淡出、反向接续和减少动态效果。

本次保存并推送 `codex/home-profile-layout` 分支，不执行网站部署。
