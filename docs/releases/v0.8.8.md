# V0.8.8

发布日期：2026-11-09

- 首页「用心创作的事物」改为作品收藏，加入中英文推荐理由、《Julie》唱片试听和 Orbit Clocks 时钟预览。
- 《朱朱之城》详情采用六张可循环切换的展览照片。蓝色封面从作品卡片平滑过渡至叠顶，照片支持任意方向拖动、短拖归位、触屏和键盘操作，并适配减少动态效果。
- 照片使用 16px 直角纸纹边框，内缘轻微渐隐。拖出堆叠区域时，照片可继续移动至弹窗边缘，避免详情区出现滚动条或布局跳动。作品收藏各卡片的详情说明宽度上限设为 640px，窄屏自动换行。
- 补充首页「屏幕之外」文案，统一首页区块留白，调整英文正文与详情段落、列表的行距和间距。
- 调整详情返回、回到顶部与代码复制控件的视觉样式，统一交互音效音量设置，同步设计系统预览、字体子集与 GitHub 贡献快照。
- `package.json` 和 `package-lock.json` 从 `0.8.7` 更新至 `0.8.8`。

验证：`npm run build` 完整通过，120 个英文页面通过出版审计。已抽查首页、移动导航、主要列表、中英文文章详情、404 和开发环境设计系统页。已验证照片堆叠的入场、拖拽和循环切换，以及七张作品卡片在桌面和窄屏下的说明宽度。
