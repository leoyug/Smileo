# V0.9.0

发布日期：2026-11-09

- 英文版标题使用 New Spirit Medium Condensed，页面分区小标题使用 New Spirit Regular Condensed。中文版分区小标题使用寒蝉锦书宋 Compact Regular，文章和项目详情标题使用 Compact Bold。
- 首页「联系到我」的四个链接复用文章列表的悬停音效，中英文「常用工具」文案保留工具介绍。
- 作品图库展开、关闭及单件作品详情的打开、关闭复用语言切换音效。《朱朱之城》通过拖动或方向键翻图时依次播放三段按需加载的音效，遵循网站音效开关。
- 统一作品详情内容间距，更新 GitHub 贡献热力图快照。
- `package.json` 和 `package-lock.json` 从 `0.8.8` 更新至 `0.9.0`。

验证：`npm run build` 通过，120 个英文页面通过发布检查。
