# V0.9.3

发布日期为 2026-11-16。

- 修复从作品详情直接跳到首页时旧封面滞留的问题。从首页精选卡片进入详情后返回，封面仍会缩回原卡片并恢复滚动位置。
- GitHub 预览卡片的贡献热力图从左向右柔和显现，并更新贡献快照。修复照片图库快速返回后残留的加载状态，改善土星时钟在窄屏上的刻度可读性和减少动态效果支持。
- 调整中英文详情标题、正文排版、目录高亮和项目参数。代码块支持显示文件名，更新复制反馈，并修正行内代码的间距与划词高亮。同步调整作品筛选、偏好面板和简历教育经历的样式。
- 设计系统预览新增 Primitives 与语义 token 分区，合并重复刻度，补齐中英文字体样张和用途。签名颜色统一为 `#716a65`。
- 将 npm 版本更新至 `0.9.3`。

验证通过 `npm run build`，120 个英文页面通过发布检查。Chromium 已检查首页、移动导航、作品与写作详情、摄影列表、404 和开发环境设计系统页。
