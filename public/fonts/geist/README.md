# Geist fonts

Geist Sans normal and italic variable WOFF2 files are copied unchanged from the official `geist@1.9.1` npm package (`dist/fonts/geist-sans/`). Both support weights 100–900. The package license is included in `Geist-LICENSE.txt`.

Upstream: https://github.com/vercel/geist-font

The existing Geist Mono Regular file and its `OFL.txt` are retained separately. Fonts are served locally; no third-party font requests are required at runtime.
